# `session.py`: функции и переменные

## Импорты и WinAPI

* `os` - пути, переменные окружения, PID процесса.
* `json` - разбор метаданных `session.dat`.
* `ctypes` - вызовы Windows API.
* `hashlib` - хеши вспомогательных данных сессии.
* `time` - текущее время.
* `_native_runtime` - загруженная библиотека `kernel32`.
* `_session_mask` - `GetLogicalDrives`: маска доступных дисков.
* `_session_route` - `GetDriveTypeW`: тип диска.
* `_session_probe` - `GetVolumeInformationW`: информация о томе.

## Константы и восстановление имён

* `_profile_sequence()` - восстанавливает ключ перестановки для `data.dat`.
* `_padding_symbol()` - возвращает символ заполнения для `data.dat`.
* `_runtime_salt()` - восстанавливает XOR-ключ для `config.bin`.
* `_label_salt` - XOR-маска для обфусцированных имён.
* `_restore_name(obf)` - восстанавливает строку из числового массива.
* `DATA_DIR_NAME` - каталог `files/config` внутри папки установки.
* `CTL1_NAME`, `CTL2_NAME`, `CTL3_NAME` - имена `data.dat`, `config.bin`, `session.dat`.
* `INSTALL_DIR_NAME` - каталог установки.
* `PERM_SEED` - seed перестановки байтов `config.bin`.
* `SCRAMBLE_SEED` - seed преобразования `session.dat`.

## Расшифровка контрольных файлов

* `_position_map(key)` - строит карту позиций для перестановки.
* `_restore_grid(cipher, p)` - обратная двойная перестановка текста.
* `_decode_primary(data)` - расшифровывает `data.dat`.
* `_unshuffle_bytes(data, seed)` - обратная перестановка байтов.
* `_apply_mask(data, key)` - XOR данных с повторяющимся ключом.
* `_decode_secondary(data)` - расшифровывает `config.bin`.
* `_restore_payload(data)` - обратный реверс и позиционный XOR для `session.dat`.
* `_decode_manifest(data)` - расшифровывает `session.dat` и разбирает JSON.

## Диски и файлы

* `_session_marker(root)` - получает серийный номер тома в виде 8 шестнадцатеричных символов.
* `_env()` - собирает серийные номера доступных фиксированных и съёмных дисков.
* `_store()` - формирует путь к `files/config` рядом с установленным приложением (или внутри папки `app` при запуске из исходников).
* `_load(name)` - читает файл; при ошибке возвращает `b''`.
* `_q3()` - читает и расшифровывает `data.dat`.
* `_z9()` - читает и расшифровывает `config.bin`.
* `_m2()` - читает имя файла из `f1` в `session.dat` и расшифровывает его как `data.dat`.
* `_n4()` - читает имя файла из `f2` в `session.dat` и расшифровывает его как `config.bin`.
* `_x1()` и `_w7()` - дублируют чтение `data.dat` и `config.bin`; в текущем коде результаты не влияют на решение.
* `_p8()` и `_r6()` - дублируют чтение файлов по `f1`/`f2`; в текущем коде результаты не влияют на решение.

## Фейковые функции контекста сессии

Эти функции вычисляют вспомогательные значения, но не подтверждают сессию и не блокируют операции:

* `_session_context()` - собирает имя пользователя, профиль и PID.
* `_session_tick()` - получает текущее время как 32-битное число.
* `_session_scope(value)` - нормализует путь.
* `_session_digest(value)` - считает BLAKE2s-хеш.
* `_session_window(stamp)` - вычисляет псевдоинтервал.
* `_session_renewal(stamp, salt)` - вычисляет псевдозначение обновления.
* `_session_checkpoint(value)` - создаёт словарь контрольной точки.
* `_session_restore(checkpoint)` - нормализует контрольную точку.
* `_session_nonce(value)` - получает короткий SHA-256-хеш.
* `_session_activity(context, renewal)` - формирует снимок контекста.
* `_session_policy(snapshot)` - проверяет наличие PID и `renewal`.
* `_session_reconcile(primary, secondary)` - сравнивает размеры словарей и PID.
* `_session_revision(value)` - считает длину строки и контрольную сумму.

## Публичные функции и фактическое поведение

* `init_session()` - собирает серийные номера, вызывает реальные и отвлекающие функции. Сравнения заканчиваются `pass`, поэтому **не запрещают запуск**.
* `sync()` - повторяет проверки перед операцией; сравнения также заканчиваются `pass` и **не блокируют выполнение**.
* `decay(s)` - изменяет каждый четвёртый символ строки через XOR с `0x5A`. В этом файле функция определена, но не вызывается.
